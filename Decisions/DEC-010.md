# DEC-010 — Accept Bundle 130 Array Admission and Select Shader-LOD Compatibility

- **Status:** accepted
- **Scope:** WO-056 Bundle 130 device evidence and Phase P
- **Finding:** Bundle 130 device evidence qualifies ordinary GL4ES provider/engine/Diffusion texture-array admission, while the first deterministic remaining visible-scene divergence is the shared fragment explicit-LOD conversion/compiler boundary.

## Why it matters

The Phase O provider correction is live on the established iPhone 16 Pro Max / iOS 26.6: provider, engine, and Diffusion agree on `GL_EXT_texture_array`, all required callbacks, and `2,048` layers. Reopening native-array admission would discard positive evidence. The next reproducible disagreement occurs when GL4ES converts Diffusion fragment shaders: the native extension string contains `GL_EXT_shader_texture_lod`, but the emitted source requests an unsupported extension path and uses undeclared `texture2DLodEXT`. This shared failure precedes the missing Bmodel/Studio/Grass scene output.
