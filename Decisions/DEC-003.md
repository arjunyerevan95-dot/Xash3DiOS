# DEC-003 — Repair Sampler-Array Uniform Classification and Use VBO-Backed GLES3 Input

- **Status:** Accepted
- **Scope:** GL4ES native texture-array sampling contract and its iOS self-test harness
- **Finding:** GL4ES omitted `GL_SAMPLER_2D_ARRAY` from three uniform-classification helpers (`uniformsize`, `is_uniform_int`, and `n_uniform`). That omission caused the observed `GL_INVALID_OPERATION` at `glUniform1i(u_Array, 0)`. The correction adds the sampler type to all three helpers. The audit also found an invalid GLES3 client-side vertex pointer; the self-test now uses a VBO-backed vertex attribute.

## Why it matters

The exact prior readback checksum, `a915906d`, showed that texture-array sampling, layer selection, drawing, readback, and drawable presentation had already succeeded despite the uniform-write error. The sampler’s default value of zero explains that result. Fixing only the reported uniform error while retaining the client-side pointer would have left a second contract violation capable of obscuring later qualification.
