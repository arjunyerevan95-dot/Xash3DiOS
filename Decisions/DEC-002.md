# DEC-002 — Use the Normal Diffusion Game-Info Bootstrap for Conformance

- **Status:** Accepted
- **Scope:** iOS renderer-conformance startup route
- **Finding:** Renderer conformance must run through the ordinary engine filesystem and game-info path: `FS_Init` followed by `FS_LoadGameInfo` for Diffusion, with real metadata. The renderer test dispatches after EAGL/GL4ES initialization and before `CL_LoadProgs`.

## Why it matters

This keeps conformance evidence representative of the shipping Diffusion startup route while isolating renderer qualification from later client/game-DLL loading. A synthetic or game-info-independent route would not prove that the test survives the project’s actual bootstrap boundary.

## Evidence

- WO-056 Phase F / Bundle 112 rejected the bypassed bootstrap route.
- WO-056 Phase G / Bundle 114 established the normal-bootstrap dispatch point and reached the native-array test on device.
- WO-056 Phase I / Bundle 116 preserves that route while correcting the renderer contract.
- [WO-056 evidence manifest](../Evidence/WO-056/manifest.md)

## What this does not establish

This decision does not qualify gameplay, client DLL loading, terrain rendering, or Bundle 116 on a physical device.

## Superseded decisions

It supersedes the withdrawn game-info-independent Phase G route and any equivalent conformance bypass of normal Diffusion metadata loading.
